03 / THE SYSTEM

One event. Four deliberate moves.

No proprietary agent. No cloud account. The same chain is visible from source to dashboard.

  1. 01

    Emit

    A simulated loop, or optional PyTorch loop, creates a record for each training step.

    loss · grad · batch
  2. 02

    Capture

    A bounded buffer preserves a small, inspectable sample before anything is transformed.

    /events
  3. 03

    Shape

    The local router validates values, normalizes timestamps, and adds pipeline context.

    training_step
  4. 04

    Route

    Prometheus receives bounded, dashboard-ready metrics. Everything else is counted as a drop.

    /metrics

04 / PORTFOLIO NOTE

Built as a working explanation, not a mock dashboard.

Veyepr is a small, production-minded demonstration of an observability boundary: Python owns the event contract; Prometheus owns time-series collection; Grafana owns the operational view.

The important decision is what does not become a label. Steps, prompts, and timestamps stay in the event stream so the metric store remains fast and affordable.
