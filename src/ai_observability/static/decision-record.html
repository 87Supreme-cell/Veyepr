DECISION RECORD

Make the product choices reviewable.

This page records the decisions made by the product lead: why the system begins with evidence, what it validates today, and what it intentionally refuses to claim.

01 Product decision

Start with AI usage evidence, not a generic score.

Decision: Veyepr first validates and observes the operational signals around AI use. It does not label a model or user “good” or “bad” from a shallow set of metrics.

Reason: A serious enterprise assessment needs a declared rubric, appropriate context, a review owner, and retained evidence. A dashboard cannot responsibly invent those inputs.

Result: The product can support future policy scoring without misleading an operator today.
02 Reliability decision

Publish the contract and verify it twice.

Decision: The event shape is a versioned JSON Schema. The Python reference pipeline and a separate Rust verifier both enforce its required fields, types, timestamps, and bounded identifiers.

Reason: Accuracy matters more than throughput for this stage. Independent implementations reduce the risk that a single runtime assumption quietly accepts bad evidence.

Result: Teams can validate an event before deployment with the same contract used by the running reference pipeline.
03 Deployment decision

Demand reproducible proof before calling it deployable.

Decision: The repository includes one command that starts the Compose stack and verifies health, contract metrics, event capture, and Prometheus scrape health. Rust verification runs in a pinned compiler container.

Reason: A preview page proves presentation, not operation. Reproducible checks create a concrete handoff for an engineer or evaluator.

Result: The next pass can harden a known baseline instead of guessing whether the demo works on another machine.

CURRENT BOUNDARY

Evidence first. Policy-driven assessment next.

Veyepr is ready to demonstrate validated telemetry collection, review-only agent-action evaluation, and local evidence packages. Output-quality grading remains deliberately deferred until its evaluation criteria, data handling, and human-accountability model are explicit.
