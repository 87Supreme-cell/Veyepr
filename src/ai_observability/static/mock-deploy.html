PASS 3 / MOCK DEPLOYMENT

REVIEW-ONLY SENTINEL

Detect, preserve, and route for review.

This local model evaluates sanitized agent-tool metadata against a declared policy. A matched rule creates a tamper-evident review package for both a security reviewer and the session subject. It does not block a request, read tokens, capture screens, or decide that a person violated policy.

SELECT AN EVIDENCE VIEW

One response level: human review.

POLICY INPUT

Declared local rules

Response
Record and route to human review only
Primary signal
Sanitized agent/tool action metadata
OAuth rule
Review scopes outside the declared allowlist
Export rule
Review sensitive exports to unknown destinations or above the local threshold
Retention
Metadata and SHA-256 content hashes only

REVIEW PACKAGE

What a reviewer can verify

Case context
Session ID, action ID, pseudonymous actor reference, tool, action type, and timestamp
Policy context
Policy ID, policy version, matched rules, and review-only disposition
Content handling
Prompt and tool-output hashes; no raw prompt or output in the package
Integrity
A SHA-256 digest that reveals later changes if the original digest is retained independently
Review parties
Security reviewer and session subject

LIMITATIONS

What this mock deployment does not do

  • It does not intercept network traffic, OAuth tokens, or real agent sessions.
  • It does not automatically pause, block, discipline, or report a person.
  • It does not retain raw prompts or raw tool outputs.
  • It does not provide immutable storage, signatures, role-based access, or case management.
  • It does not determine malicious intent; a review-required result is a request for human context.
